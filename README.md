This project is for the MMO (Albion Online)

It uses an API that contains data from the games market and calculates profitable opportunities within the market.
One example is finding profitable enchantments. The app requests data from the API and scans through it to find items that are currently selling for more than the cost of buying the base items and enchanting them. 


Ex, Tier 5.2 sword selling for 500,000
Base Tier 5 sword sells for 100,000
Item cost to enchant to 5.2 is 200,000

Total profits = 200,000
